# Data

The raw CSVs are NOT committed to this repository. Download them yourself:

- Original source (Kaggle, published by Olist): https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
- Olist's own mirror (no login needed): https://github.com/olist/work-at-olist-data/tree/master/datasets

Place these 9 files in this folder:
olist_orders_dataset.csv, olist_order_items_dataset.csv, olist_order_payments_dataset.csv,
olist_order_reviews_dataset.csv, olist_customers_dataset.csv, olist_products_dataset.csv,
olist_sellers_dataset.csv, olist_geolocation_dataset.csv, product_category_name_translation.csv
